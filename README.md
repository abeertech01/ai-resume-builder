# 📝 AI Resume Builder

Build and download professional resumes instantly using AI.  
[👉 Live Demo](https://ai-resume-builder-eight-kappa.vercel.app)

![App Screenshot](https://via.placeholder.com/1200x600?text=Screenshot+Coming+Soon)

---

## ✨ Features

- ⚡ **AI-Assisted Resume Generation** – Instantly generate professional resume content using integrated AI.
- 📄 **Multiple Resumes** – Create and manage multiple resumes under one account.
- 🌈 **Pro Plan** – Unlock premium features like multiple color themes and unlimited resumes with a subscription.
- 🧠 **Smart & Fast** – Streamlined UI and intelligent defaults to make the process smooth.

---

## 🧰 Tech Stack

- [Next.js 15](https://nextjs.org/) (App Router, Server Components)
- [React 19](https://react.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Shadcn UI](https://ui.shadcn.com/)
- [Prisma ORM](https://www.prisma.io/)
- [Clerk](https://clerk.com/) for authentication
- [Stripe](https://stripe.com/) for payments
- [Gemini API](https://ai.google.dev/) for AI content generation

## 🚀 Getting Started (Optional)

> This section is for developers who want to run it locally.  
> If you're just exploring, skip to **Usage** below.

```bash
# Clone the repo
git clone https://github.com/abeertech01/ai-resume-builder.git

# Navigate into the project
cd ai-resume-builder

# Install dependencies
npm install

# Run the development server
npm run dev
```
